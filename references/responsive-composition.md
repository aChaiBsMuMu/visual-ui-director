# Responsive composition

Preserve hierarchy and Visual DNA across available space by recomposing, not uniformly scaling.

## Layer model

1. Brand Layer: color intent, imagery, icon grammar, type character, motion personality.
2. Product Visual Layer: content priority, signature gestures, task-specific composition.
3. Platform Adaptation Layer: native navigation, controls, input, accessibility, and state behavior.
4. Device Context Layer: viewport, window, orientation, safe area, posture, glance duration, and distance.

For every priority surface define focal element, reading order, grid or alignment anchors, content measure, fixed versus scrolling regions, image ratios, density curve, and failure thresholds. At each threshold specify what wraps, stacks, collapses, moves, becomes a sheet/pane, or is removed.

Choose breakpoints from content failure and platform behavior. Test narrow, intermediate, and expanded conditions where applicable. A watch screen, phone, tablet, desktop window, and wide web canvas should share identity but not necessarily navigation, geometry, or information volume.
