# Imagery and material

Define Medium (photography/illustration/3D/generated), Subject, Camera Angle, Crop, Lighting, Depth, Background, Color Grade, Texture, Image Ratio, Image Mask and Image Density. State whether each image carries information, emotion or both; test the layout without the asset.

Specify Fallback, Placeholder and Loading, crop focal point across devices and acceptable asset quality. If no imagery is appropriate, keep IMAGERY.md with a reason and show the deliberate absence in the style tile. Surface material includes permitted blur, translucency, texture and depth with budgets; decoration must support the thesis.

For generated assets, supply subject/composition/lighting/material/crop instructions, exclusions and acceptance criteria; use image generation for expressive media, never exact UI layout. Keep licensing/attribution and unavailable assets explicit. The style tile may embed a local authorized raster; a labeled placeholder is useful for fallback review but does not validate a photography direction that depends on real imagery.
