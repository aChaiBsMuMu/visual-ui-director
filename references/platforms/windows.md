# Windows adaptation

Design for resizable windows, precise pointer input, keyboard productivity, accessibility settings, and information-dense workflows.

- Define minimum window size, preferred content width, responsive pane behavior, title bar treatment, window controls, and high-DPI scaling.
- Support keyboard navigation, access keys/shortcuts where appropriate, visible focus, screen readers, high contrast, text scaling, pointer hover, right-click/context menus, and touch when the device supports it.
- Use platform-native window, dialog, menu, selection, drag/drop, notification, and back/navigation behavior unless the approved thesis requires a deliberate variation.
- Preserve shared brand semantics while mapping surfaces, typography, density, icons, and motion to the selected Windows stack.
- Validate empty, loading, error, disconnected, narrow-window, maximized, and multi-monitor/DPI conditions as relevant.

Render at the minimum supported window and the primary working size. Test both keyboard-only and pointer flows for core tasks.
