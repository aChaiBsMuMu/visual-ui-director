# Spacing rhythm

Spacing must create cadence and hierarchy rather than repeat one comfortable interval.

Define project-specific ranges for:

- **Micro:** icon-label, glyph, and inline relationships
- **Component:** internal control and item spacing
- **Section:** relationships within one content thought
- **Macro:** separation between major decisions or regions
- **Hero:** intentional opening or focal space

A possible starting relationship is Micro 4–8, Component 12–20, Section 24–40, Macro 48–80, and Hero 80+, but derive actual values from content, platform, density, and the approved composition.

Document controlled exceptions and responsive compression. Audit adjacent gaps by role: identical numerical values can still be wrong when semantic relationships differ. Avoid solving hierarchy with borders and cards when whitespace can express it more clearly.
