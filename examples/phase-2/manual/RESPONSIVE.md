# 静读 / Margin — Responsive

Fictional demonstration; proposed design, not a sampled production system.

## Brand Layer

Brand preserves warm neutral canvas, serif title character, controlled brick accent and consistent outline symbols. It does not dictate identical positions across windows.

## Product Visual Layer

Product preserves the title-first decision, uncontained archive and continuous reading column. The primary focus and reading path survive width changes.

## Platform Adaptation Layer

Web uses native browser links, semantic inputs and buttons, keyboard order, visible focus and normal history. Branded appearance does not replace those behaviors.

## Device Context Layer

Compact width stacks decision regions; wider windows separate title from synopsis. Safe content margins, text reflow and pointer/touch affordances respond to available space.

## Navigation Safe Area Density and Input

Navigation stays a concise text row. Safe area padding follows host browser context. Dense archive metadata never gets the same emphasis as the title. Inputs remain visibly editable.

## Native Controls Typography Touch and Pointer

Keyboard focus is visible for buttons, links and filter controls. Typography keeps semantic heading roles; pointer hover may underline links without creating a new surface. Touch must not depend on hover.

## Window and Watch Context

This fixture targets a responsive web reading product. Watch contexts and native mobile controls are explicitly outside scope; no bottom tab bar is generated. A future wearable surface needs its own platform adaptation.

## Smallest Target and Transformations

The representative screen is compact; atlas includes compact and wide relationships. Long Chinese/English titles wrap vertically. Check the smallest supported browser width and text zoom before claiming production conformance.
