# Layout and composition

LAYOUT.md defines grid columns, margins, gutters, max/content width and alignment anchors; primary/secondary/tertiary/background hierarchy; first/second/third reading path; low/medium/high density by region; micro/component/group/section/macro/hero whitespace; left/center/right/mixed alignment and intentional breaks; dominance ratios and what recedes.

Explain when a hero image, display title or special datum may break the grid and which task pages prohibit breaks. Specify fixed versus scrolling regions. At content failure thresholds recompose: stack, relocate, collapse, reprioritize or change navigation, rather than merely shrinking.

PAGE_PATTERNS.md is a scope-derived pattern library. Each pattern includes Name, Purpose, Best For, Primary Focal Point, Reading Path, Regions, Density, Visual Ratio, Scrolling Behavior, Allowed Components, Avoid and Responsive Transformation. Hero Decision, Editorial List, Data Summary, Detail Narrative, Split Content, Image-led Detail, Command Workspace, Settings Form and Feed are examples, not a mandatory catalog.

SPECIMENS.json describes each chosen pattern's regions using normalized coordinates and hierarchy labels, plus compact/expanded variants for supported contexts. Render every major pattern into layout-atlas.svg. Show wireframes, labels, regions and relationships. A generic card grid must not stand in for every pattern. Atlas is composition evidence; representative screen is the integrated UI test.
