# Visual standard — compatibility entry

The canonical standard is now the [Phase 2 UI Design Manual](phase-2/design-manual.md), still versioned under `.design-director/standards/<version>/`. Do not create a parallel DESIGN_SYSTEM directory.

Read [strategy](phase-2/design-strategy.md), [Visual DNA](visual-dna.md), [visual specimens](phase-2/visual-specimens.md) and [Gate B](phase-2/gate-b-validation.md). Existing color/type/spacing/imagery/motion references remain available; the complete scope-aware discipline rules are routed by the [Phase 2 overview](phase-2/phase-2-overview.md).

Semantic Tokens and Platform/Page Overrides remain intact. Prefer semantic color, typography, radius, space and motion roles over raw palette names. The concise MASTER links detailed rules; parameters live in TOKENS.json. A bounded page exception records Screen, Override, Reason, Scope and Does Not Change through the existing CLI.

SPACING_GEOMETRY.md replaces SPACING.md as the canonical geometry document; SPACING.md remains a compatibility router. Root visual-dna.md aliases the current version's VISUAL_DNA.md. Read [migration](../MIGRATION.md) before upgrading an existing workspace.
