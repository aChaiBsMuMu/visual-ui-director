# Color discipline

Define color as a governed visual budget, not a list of swatches.

For each important color record:

- semantic role and priority
- light/dark values and tested foreground pairs
- visible-area budget or frequency
- allowed contexts
- prohibited contexts
- state behavior and platform aliases

Example: brand green may occupy 5–12% of the visible interface, reserved for primary confirmation, selected state, and positive progress; it must not become a page background, default icon color, or decorative gradient.

Consolidate near-duplicates, keep neutrals intentional, and define focus, disabled, destructive, warning, success, and information roles. Sampled reference colors are evidence, not automatically accessible tokens. During screenshot review, judge the rendered proportion and competition—not only token correctness.
