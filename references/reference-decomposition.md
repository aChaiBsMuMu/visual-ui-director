# Reference decomposition

Use after Gate A. The primary reference controls overall grammar; secondary references affect only their contracted traits.

## Reference types

Classify each source as one or more of: Product, Visual, Layout, Interaction, Typography, Imagery, Brand/Editorial, or Motion reference. A full application screenshot is not required; adjacent editorial, spatial, packaging, or photographic work may provide one bounded contribution.

## Required record

For every source write: Reference, Type, Contribution, Do Not Copy, Observed, Inferred, and Proposed.

Describe hierarchy, composition, palette, typography, spacing, geometry/material, iconography, imagery, interaction, motion potential, content fit, platform fit, and implementation risk only where the source offers evidence.

## Synthesis rules

- Trace every proposed system decision to product need, primary grammar, a permitted secondary contribution, or a clearly labeled new proposal.
- Never import a rejected trait through another category.
- Resolve conflicts explicitly; do not average incompatible references into a style collage.
- Preserve source and creator attribution where available.
- Record unknown fonts, tokens, responsive behavior, and motion as unknown or inferred—not observed.
