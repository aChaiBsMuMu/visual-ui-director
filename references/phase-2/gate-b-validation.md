# GATE B — STRATEGY & DESIGN MANUAL LOCK

Gate B approves strategy, 5–8 Visual DNA principles, all manual disciplines, scope-derived page patterns, seven visual sheets and the representative screen. Guided/Reference-led require the user's approval already expressed in the session; Direct records an assumed lock only after identical completeness validation. Direct never bypasses design thinking.

After actual visual inspection and completing REVIEW.json, run `phase2 review` to bind the inspected manual/evidence hashes. Then run `phase2 validate`, present the strategy/manual and visual evidence, resolve failures, then `approve --gate b --version v1`. Existing --style-tile, --representative-screen and --wireframe flags remain supported as evidence imports; wireframe is supplemental to the mandatory layout atlas and imported style tile supplements the generated style-tile.svg.

Validation checks reference preconditions and loaded contract hash; completed document sections/no obvious scaffolding; 5–8 distinct DNA entries with pass/failure/provenance in review; tokens/config types and references; scope inventories and states; influence contribution boundaries; configured contrast pairs; legal nonempty SVG with text and dimensions; generated file hashes; representative image format; review coverage and evidence; required manual files. Narrow component/motion exclusions need item, scope, reason and alternative. Required files and core evidence cannot be waived.

Coherence review covers Color, Typography, Layout, Geometry, Components, Icons, Imagery and Motion against one thesis. Also explicitly inspect secondary leakage, rejected traits, decorative dependency, actual content fit, smallest target, component-token agreement and representative-manual agreement. Each REVIEW.json check has pass, evidence and reasoning. Automated validation verifies these review records; it cannot independently judge aesthetics from prose.

On success persist a SHA-256 lock over reference inputs, manual, tokens, specs, review, overrides present at lock time and evidence. `status --require implement` and Gate C reject stale locks. Keep snapshot hashes of previously locked versions to prevent rewriting a historical version after selecting new references. Use `phase2 upgrade --version NEW` for global changes; the existing `override` command records bounded single-page exceptions without changing the locked master.
